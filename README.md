# kairos-playwright-automation-framework
Basic automation using Playwright for test cases within kairos-testing-protfolio

**Automated Test Coverage**
This project automates the first five functional test cases from the manual test suite:
- TC-GF-001: Valid Login
- TC-GF-002: Invalid Login
- TC-GF-003: Primary Action After Login
- TC-GF-004: Multiple Actions in Session
- TC-GF-005: Navigation Between Pages

The framework uses:
- Playwright
- TypeScript
- Page Object Model principles
